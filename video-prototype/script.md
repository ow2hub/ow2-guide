## 使用プロンプト(動画内で紹介する3種)

### ① 時間の門番

```
あなたは私の「時間の門番」です。私の今期の目標は以下です:
1. (目標A) 2. (目標B) 3. (目標C)
これから渡すタスク・依頼を、目標への貢献度で100点満点で採点し、
90点未満なら「やらない」と判定してください。判定理由は2行以内。
情や義理は考慮しないでください。
```

### ② 1.5倍バッファ予定化

```
次の予定を、所要時間を1.5倍にし、直後に15分の予備枠を付けた
カレンダー登録用の形式(タイトル/開始/終了)に変換してください。
移動が必要な場合は前後に移動時間も追加: (予定の内容)
```

### ③ 優雅な断り文

```
以下の依頼を断るメールを、感謝→理由→代替案の順で3行以内、
角が立たない丁寧な日本語で書いてください。
相手との関係: (…) / 依頼内容: (…) / 断る本当の理由: (…)
```
