# 仮動画 台本 — 第1回「時間術の本30冊をAIに分析させたら、共通点は3つしかなかった」

チャンネル: **AI実践読書ラボ** — 本の教えを、AIで実行可能にする検証チャンネル
形式: **漫画風ポップアニメ + 2キャラ掛け合い + VOICEVOX音声(顔出し・声出しなし)**

`youtube-book-ai-strategy.md` の戦略に基づくプロトタイプ。
**検証数値はすべてサンプル用のダミー。** 公開前に必ず実測値へ差し替えること。

---

## なぜこの企画なのか(フォーマットB: 横断分析型)

「1週間実践してみた」系は会社員としての実務が必要になるが、**横断分析型は机の上だけで一次情報が作れる**。

- 数字の出どころ = 自分で行った集計。世の中に存在しないデータなので完全にオリジナル
- YouTubeの Inauthentic Content ポリシー(量産テンプレの収益化不可)に対して、
  「独自の調査 + 独自の結論」があるので安全側に立てる
- 本要約チャンネルの上位互換に見える(「30冊読まなくていい」は強いフック)
- ネタが尽きない: お金の本30冊、営業本30冊、健康本30冊…

### 著作権上の設計

**本文の全文はAIに入れない。** 目次・公開されている紹介文・自分の読書メモのみを使う。
これを動画内でも明言する(検証方法のシーン)。誠実さは信頼になるうえ、法的にも安全側。
結論も「要約では足りない、本を読め」に着地させるので、出版社にとっても好ましい。

### 使用している数値(すべてダミー / 相互に整合)

| 項目 | 値 |
|---|---|
| 分析対象 | 30冊(洋書14 / 和書16) |
| 抽出した主張(延べ) | 251個(1冊あたり平均8.4個) |
| ユニーク主張 | 41種類 |
| 20冊以上に登場 | 3種類(24 / 22 / 21冊) |
| 15〜19冊 | 4種類(18 / 17 / 16 / 15冊) |
| 2〜14冊 | 15種類(早起き8・朝活6・ポモドーロ9 を含む) |
| 1冊のみ | 19種類 |

内訳の合計は 3+4+15+19 = **41種類**、延べは 67+66+99+19 = **251個** で一致する。
`analysis/make_dummy.py` でこの分布のデータを生成し、`aggregate.py` に通して
同じ数字が出ることを確認済み(= 視聴者が検算しても破綻しない)。

### 動画の核になる主張

> 共通の3つは、どの本にも書いてある = 要約で足りる部分。
> でも本当の価値は「その本にしかない19個」のほうにある。
> **要約は地図、本は現地。**

要約チャンネルへのアンチテーゼでありながら、本を売る方向に着地する。差別化と安全性を両立させる結論。

## キャラクターと音声

| 役 | キャラ | 見た目 | VOICEVOX 話者 | 口調 |
|---|---|---|---|---|
| 後輩・ツッコミ | ノア | ミント髪ツインテール + 黄色リボン | 春日部つむぎ (speaker 8) | 〜です / 〜ですか? |
| 先輩・解説 | メイ先生 | ローズ髪ロング + メガネ | 四国めたん (speaker 2) | 〜だわ / 〜よ |

2人とも女の子。髪型・髪色・小物・メガネの有無で見分けがつくようにしてある。

話者は `build_video.py` の `SPEAKERS` で変更可能
(3=ずんだもん / 11=玄野武宏 / 13=青山龍星 / 14=冥鳴ひまり など)。

### VOICEVOX 利用上の注意

- VOICEVOXは**無料・商用利用可**だが、**キャラクターごとに利用規約があり、クレジット表記が必須**。
  概要欄に `VOICEVOX:春日部つむぎ` `VOICEVOX:四国めたん` のように記載する。
- **本スクリプトが描くキャラ絵はオリジナルの簡易イラスト**であり、VOICEVOXキャラクターの
  立ち絵ではない。公式立ち絵は別途ライセンス確認が必要。
- 合成音声を使うので、YouTube Studio の**AI・合成コンテンツの開示設定をONにしておく**。

## 実装されている演出

- 吹き出しのポップイン(オーバーシュート付き)
- **口パク**: 合成した音声の音量エンベロープに同期して口の開きが4段階で変化
- まばたき / 話している側だけ体が上下に揺れる
- 聞き手側のキャラは彩度を落として、話者を目立たせる
- 横棒グラフの伸長アニメ・大数字のカウントアップ(ease-out)
- 驚きのシーンに集中線
- フレームはffmpegへ直接パイプ(中間PNGを吐かないので高速・省ディスク)

### 未実装(本番までにやるとよい)

- キャラの表情差分(驚き・呆れ・笑顔)
- シーン間のワイプ/スライド遷移
- Shorts用の縦型(1080x1920)書き出し

## 使い方

```bash
# VOICEVOXを使う場合: 先にVOICEVOXアプリ(Mac版)を起動しておくだけ
python3 build_video.py ./build              # 自動検出
python3 build_video.py ./build --engine voicevox
python3 build_video.py ./build --engine openjtalk   # 仮ナレーション

# 必要パッケージ
#   brew install ffmpeg
#   pip3 install pillow numpy
```

出力: `build/sample_video.mp4` / `build/thumbnail.png` / `build/narration.wav`

※上の概要欄テンプレのチャプター時刻は Open JTalk 版(11分50秒)のもの。
　VOICEVOX に切り替えると尺が変わるので、書き出し後に実際の時刻で貼り直すこと。
