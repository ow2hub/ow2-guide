## 手順(目次を集めたあと)

```bash
python3 check_books.py                 # 抜けの確認
python3 make_prompts.py                # ★ --intro-only は付けない(目次も使う)
```

15冊 = 2バッチ。`aggregate.py` は2回一致で採用するので、**投げるのは2回ぶんで足りる**。

```
prompts_out/batch1_run1.txt  →  responses/batch1_run1.txt
prompts_out/batch1_run2.txt  →  responses/batch1_run2.txt
prompts_out/batch2_run1.txt  →  responses/batch2_run1.txt
prompts_out/batch2_run2.txt  →  responses/batch2_run2.txt
```

**AIへの貼り付けは4回。** 毎回「新しいチャット」で。

```bash
rm responses/*.txt                     # 第1回の答えを消す(条件が変わるため)
pbcopy < prompts_out/batch1_run1.txt   # 貼る → 返答をコピー
pbpaste > responses/batch1_run1.txt
```

そのあと名寄せと集計:

```bash
python3 aggregate.py --list-claims > claims.txt   # 主張が100件以上出るはず
# prompts.md の【名寄せプロンプト】+ claims.txt をAIに投げ、canonical.json を作る
python3 aggregate.py
```

**第2回は名寄せを飛ばさないこと。** 目次だと表現ゆれが一気に増えるので、
名寄せなしだとランキングが割れて結論が出ない。

最後に `report.md` と `video_numbers.py` を見せてもらえれば、台本を書いてビルドする。

| # | セクション | 内容 |
