# チャンネルのブランディング

画像は `python3 make_branding.py` で生成する(`branding/icon.png` `branding/banner.png`)。
名前を変えたいときは `make_branding.py` の冒頭 `NAME` / `TAGLINE` / `SCHEDULE` を書き換えて再実行。

---

## チャンネル名

### 推奨: **本のデータ研究所**

第1回の中身が「本をデータで検証する」になったので、それをそのまま名前にしたもの。

- **何のチャンネルか一度で伝わる** — 説明が要らない
- **拡張性がある** — 紹介文・目次・レビュー・価格・刊行年、数えられるものは全部入る
- **「研究所」が誠実さと噛み合う** — 毎回「この分析の限界」を開示する構成と相性がいい
- **検索に「本」が入る**

### 代案

| 名前 | 向き / 不向き |
|---|---|
| 読む前ラボ | 「読む前にわかることを増やす」という価値が直接出る。短くて覚えやすいが、何のジャンルか分かりにくい |
| 積読の科学 | キャッチー。ただし「積読を減らす」チャンネルだと誤解されやすい |
| AI実践読書ラボ | 当初の名前。「本の教えをAIで実行する」意味なので、今の内容とはズレている |

## ハンドル(@から始まるID)

半角英数のみ。上から順に空いているものを取る。

1. `@hon-data-lab`
2. `@hondatalab`
3. `@book-data-lab`

## チャンネル説明(概要欄にそのまま貼る)

```
本を「読む前にわかること」を増やすチャンネルです。

同じジャンルの本をまとめてAIに読ませ、
何が共通していて、何がその本にしかないのかを数えています。

・感想ではなく、集計した数字で話します
・分析の手順と、その限界を毎回そのまま公開します
・要約ではありません。本の中身は本で読んでください

毎週金曜 19時 更新

音声: VOICEVOX
※音声合成・AI編集ツールを使用しています
```

## キーワード(YouTube Studio の「キーワード」欄)

```
読書, 本, 書評, 本の選び方, ビジネス書, 読書術, データ分析, AI分析, 時間術, 積読
```

## 画像の仕様

| 用途 | サイズ | 注意 |
|---|---|---|
| アイコン | 800x800 | 円形に切り抜かれる。端に情報を置かない |
| バナー | 2048x1152 | 中央 1235x338 が全デバイスで見える安全領域。文字はここに収める |

バナーのキャラは安全領域の外に置いてあるので、スマホでは切れてPC・TVでのみ見える。
これは意図的(スマホでは名前と更新曜日だけが見えればよい)。
