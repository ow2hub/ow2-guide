# 第4回 台本 —「対立していると思った2冊を突き合わせたら、対立は1個だけだった」

チャンネル: **本のデータ研究所**
台本の本体: `ep4.py`(`build_video.py --episode 4` で読み込む)

**数値はすべて実データ。** 集計結果は `../analysis/compare_report.md`。

## 使用している数値(すべて実測)

| 項目 | 値 |
|---|---|
| 対象 | 『読書を仕事につなげる技術』(山口周) / 『本の「使い方」』(出口治明) |
| 使ったデータ | 両書の目次(原文のまま引用させて比較) |
| 採用基準 | 同じ処理を2回実行し、**両方で同じ判定になったものだけ** |
| 出てきた論点 | **22個** |
| **正面から対立** | **1個**(2割だけ読む ⇔ 速読より熟読) |
| **一致** | **2個**(古典を読む / 再読する) |
| 山口周にしか無い | **11個** |
| 出口治明にしか無い | **8個** |
| **片方にしか無い割合** | **19/22 = 86%** |

## 3回ぶんの比較(この回の背骨)

| | 対象 | 片方(1冊)にしか無い |
|---|---|---|
| 第2回 | 時間術 14冊 | 78/89 = **88%** |
| 第3回 | 読書術 13冊 | 55/68 = **81%** |
| 第4回 | 読書術 **2冊** | 19/22 = **86%** |

**冊数もジャンルも母集団も変えたのに、同じ形が出ている。**

## この回の核になる主張

> 前回「この2冊は対立している」と言った。突き合わせたら、**対立は1個だけ**だった。
> しかも読み方が正反対の2人が、**古典と再読では一致**していた。
> 残り19個は対立ですらない。**そもそも別の話をしていた。**
> 山口周は「仕事の成果」の本、出口治明は「教養」の本。
> **同じ棚にあるだけで、答えている問いが違う。だから自分の目的で選べ。**

### 前回の訂正をそのまま出す

第3回で「対立している」と断定したのは、**この検証をする前**だった。
順番をそのまま開示することが、このチャンネルの形になっている
(第1回・第2回も仮説が外れた過程をそのまま出している)。

## タイトル案

1. 対立していると思った読書術2冊を突き合わせたら、対立は1個だけだった
2. 「2割だけ読め」と「速読より熟読」の2冊は、実は同じことを言っていた
3. 【訂正】前回「この2冊は対立している」と言ったのは間違いでした

## 概要欄テンプレ

```
本を「読む前にわかること」を増やすチャンネル「本のデータ研究所」です。

前回、読書術の本13冊を数えたときに「この2冊は対立している」と言いました。
今回はその2冊の目次を、1項目ずつ突き合わせて確かめました。

【分析方法】
・対象は『読書を仕事につなげる技術』(山口周)と『本の「使い方」』(出口治明)
・使用したのは両書の目次のみ(本文は不使用)
・目次の項目名は要約せず、原文のまま引用させて比較
・一致 / 対立 / 片方だけ に分類し、2回の実行で同じ判定だったものだけ採用

【結果】
・出てきた論点: 22個
・正面から対立していた論点: 1個(「2割だけ読む」⇔「速読より熟読」)
・一致していた論点: 2個(「古典を読む」「再読する」)
・片方にしか無かった論点: 19個(86%)
・第2回は88%、第3回は81%。冊数を変えても同じ形が出ています

【結論】
この2冊は対立していたのではなく、そもそも目的が違う本でした。
山口周さんは「仕事の成果」の本、出口治明さんは「教養」の本です。
```
