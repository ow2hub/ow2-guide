# 広告素材 一式(コピペ用)

開設後、campaign作成画面にそのまま貼る用。文字数はGoogle広告の日本語上限
(見出し=全角15字/説明文=全角45字)に収めてある。

遷移先URL(公開後のLPに差し替え):
```
https://ow2hub.github.io/ow2-guide/lp/?utm_source=google&utm_medium=cpc&utm_campaign=pretest01
```
X用は `utm_source=twitter` に変える。

---

## ① Google 検索広告(レスポンシブ検索広告)

### 見出し(15個・各全角15字以内。多いほどGoogleが最適化する)
1. 交代勤務の生活リズム管理
2. 夜勤明け、いつ寝る？
3. シフトを入れるだけ
4. 2交代・3交代に対応
5. 睡眠・光・食事を提案
6. 家族に"寝てる時間"を共有
7. 体内時計を整えるアプリ
8. 夜勤の体調管理に
9. カレンダーじゃ整わない
10. 三交代の眠り方を提案
11. 買い切り・広告なし
12. 事前登録で500円オフ
13. 夜勤前の仮眠も提案
14. シフト勤務の睡眠改善
15. 二交代のリズム対策

### 説明文(4個・各全角45字以内)
1. 早番・遅番・夜勤。シフトを入れると、いつ寝て・光・食事のタイミングを提案します。
2. 夜勤明けの睡眠、もう迷わない。交代勤務の体調管理を、体内時計から整えるアプリ。
3. 今週の睡眠・仕事・フリーを家族に共有。「今は寝てる」がひと目で伝わります。
4. サブスクなし・広告なしの買い切り。2交代も3交代も、テンプレですぐ使えます。

### キーワード(フレーズ一致 = 前後に " " を付ける)
```
"夜勤明け 寝れない"
"三交代 生活リズム"
"夜勤 睡眠 コツ"
"交代勤務 体調管理"
"二交代 きつい"
"夜勤 生活リズム 整える"
"シフト 睡眠 アプリ"
```

### 除外キーワード(求職者トラフィックを弾く=予算のムダ防止)
```
求人 転職 募集 バイト 派遣 給料 年収 求職
```

### キャンペーン設定
- 目標: なし(目標なしでキャンペーン作成)/ キャンペーンタイプ: **検索**
- ネットワーク: **検索ネットワークのみ**(「ディスプレイに拡張」は**オフ**)
- 地域: 日本 / 言語: 日本語
- 予算: **1日 ¥700**(7日で約¥5,000)
- 入札: **クリック数の最大化**、上限CPC **¥80** を設定
- 最終ページURL: 上記のGoogle用URL

## ② X(旧Twitter)広告

### キャンペーン設定
- 目的: **ウェブサイトのトラフィック(クリック)**
- 予算: 総額 ¥5,000 / 1日上限 ¥700 前後
- 期間: 7日
- オーディエンス:
  - キーワード: `夜勤` `交代勤務` `三交代` `二交代` `夜勤明け` `シフト勤務`
  - 興味関心: 仕事・キャリア / 健康・フィットネス
  - 地域: 日本 / 言語: 日本語
- 配置: おすすめ(タイムライン)

### 投稿文(3案・各280字以内。ABテスト)
1.
```

シフトを入れるだけで「寝る・光・食事」のベストな時間を提案するアプリ作ってます。
2交代も3交代もOK。事前登録で早期割引→ [LPのURL]
```
2.
```
昼に寝てるの、家族に伝わらなくて起こされる問題。
「今は睡眠中=起こさないで」が家族にひと目で伝わる、交代勤務のための生活リズム共有アプリ。
先行登録受付中→ [LPのURL]
```
3.
```
シフトカレンダーは"記録"するだけ。体は整わない。
シフトから睡眠・光・食事を提案して、体内時計ごと整える。2交代/3交代対応の買い切りアプリ、事前登録はこちら→ [LPのURL]
```

※ 画像は LP ヒーローの週間バンド(2交代・3交代)のスクショが有効。
