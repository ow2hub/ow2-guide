# ステップ2: 要件定義 —「シフトリズム」(仮称)

日付: 2026-07-09 / ステータス: LP検証前ドラフト
※ 旧「頒布帳(同人売上管理)」の要件は廃案。本ファイルは新アイデアで全面書き直し。

## プロダクト概要

交代勤務者(**2交代=日勤/夜勤、3交代=早番/遅番/夜勤**)とその家族のための「生活リズム共有」アプリ。
自分のシフトを入れると "いつ寝て・いつ光を浴びて・いつ食べるか" をルールベースで提案し、
体調・睡眠を記録してパターンを可視化。家族には「仕事時間」ではなく
「体内時計(睡眠・回復の時間帯)」を共有して、生活の衝突を減らす。

キャッチ: **「カレンダーじゃなく、体内時計を。」**

## ターゲットペルソナ

**主ペルソナ**: 製造業などの交代勤務者(20〜40代)。2交代(日勤/夜勤)または3交代(早番/遅番/夜勤)で
体調とリズムが崩れ、夜勤明けの睡眠タイミングに毎回悩む。既存のシフトカレンダーアプリは使っているが
「予定を書くだけ」で体調管理には役立っていない。
※ オーナー自身は3交代の当事者。設計は3交代を最も濃く作り込みつつ、2交代も一級市民として対応する
(2交代のほうが従事者数は多く、市場は広い)。

**副ペルソナ(共有の受け手)**: 勤務者の家族(配偶者・親)。相手がいつ寝ているか分からず、
起こしてしまう/予定が合わない。相手の「回復時間」を尊重して家事・育児・外出を組みたい。

## 解決するペイン

1. 夜勤明け・シフト切替時に「いつ寝て、いつ起きればいいか」が分からず体調を崩す
2. 対処法(順回しの原則・光/食事のタイミング)は世に情報があるが、自分のシフトに
   当てはめて教えてくれるものが無い
3. 家族に自分の生活リズムが伝わらず、睡眠を邪魔される/予定が噛み合わない
4. 体調と睡眠の記録がなく、「どのシフトの並びが自分に一番きついか」が分からない

## 差別化(なぜ既存シフトアプリで代替できないか)

既存の200万DL級アプリは「シフト=予定を色分けして記録・共有するカレンダー」。
本プロダクトは「シフト=体内時計への入力」と捉え、**睡眠/光/食事の最適タイミング提案**と
**"回復時間"の家族共有**という、カレンダー勢が構造的に踏み込まない領域を主役にする。

## MVPスコープ

### 入るもの

- **シフト入力エンジン**(土台): 詳細は docs/07。**固定周期でない人が現実に多い**ため、
  2つの入力方式を同じデータに書き込む:
  - **(A) ブロック入力[主]**: 「昼勤×4日」「休×1日」…と連続日数をまとめて積む。不定期に強い。
    **これがMVP最優先**(オーナーも固定周期なし・有給等でズレる実態)
  - **(B) サイクル繰り返し[オプション]**: サイクル配列＋起点日で無限展開。固定周期の人向け。
    プリセット: 2組2交代 / 3組2交代(2昼2夜2休・4昼2休4夜2休・3昼3夜3休) / 2組3交代 / 4組3交代 / 日勤のみ
  - 勤務種別は「昼/夜/休」を基本に。**早出は不定(直前決定)なので入力時に選ばせず、
    各日ワンタップで切り替える"当日属性"**(既定=普通)として別レイヤーで持つ。時間帯は編集可
- **生活リズム提案**: 各勤務日に対し、推奨する睡眠時間帯・仮眠・光を浴びる時間・
  食事タイミングをルールベースで提示(既知の交代勤務向け知見に基づく。医療行為ではない旨を明記)
- **体調・睡眠ログ**: 就寝/起床の記録+体調3段階(良い/普通/だるい)。1タップで完了
- **リズム可視化**: 週間・月間で「仕事/睡眠/フリー」を時間帯バンドで表示。体調の推移も重ねる
- **家族共有ビュー**: 週間の「仕事/睡眠/フリー」バンドを画像 or 読み取り専用リンクで出力し、
  LINE等で共有(相手はアプリ不要で見られる)。「今は睡眠中=起こさない」が一目で分かる
- **PWA・オフライン・ローカルファースト**: 端末内保存。会場や休憩中でも動く

### 入らないもの(非ゴール)

- 医療・診断機能、睡眠スコアの科学的厳密性(提案はあくまで一般的知見のガイド)
- ウェアラブル連携・自動睡眠検知(v2以降。MVPは手動ログ)
- 複数人のリアルタイム双方向同期(MVPは片方向の共有ビュー出力で代替)
- 給与・手当計算(お金は今回の主軸ではない。将来オプション)
- ネイティブアプリ(MVPはPWA)

## 技術構成(案)

- フロント: Web(SPA)+PWA(オフライン必須)
- データ: ローカルファースト(IndexedDB)+エクスポート。アカウント/同期はv2
- 共有: 週間ビューを画像化(Canvas)して保存/シェア。読み取り専用リンクはv2で検討
- ホスティング: 静的ホスティング(GitHub Pages / Cloudflare Pages)
- 決済: 買い切りライセンスキー(Stripe Payment Links 想定)
