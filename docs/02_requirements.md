# ステップ2: 要件定義 — 「頒布帳(はんぷちょう)」(仮称)

日付: 2026-07-09 / ステータス: LP検証前ドラフト

## プロダクト概要

同人サークル・個人クリエイターのための売上・在庫・損益管理アプリ。
イベント頒布(即売会)と通販(BOOTH/とらのあな/メロンブックス等)を横断して記録し、
年末棚卸しと確定申告用の集計まで一気通貫でこなす。「手作りスプレッドシートからの卒業」。

## ターゲットペルソナ

**主ペルソナ**: 副業同人作家(20〜40代)。年2〜4回イベント参加+BOOTH常設。
年間利益20万円前後〜で確定申告ラインを意識し始めた層。現状はExcel/スプシ/記憶で管理。

**副ペルソナ**: 専業・セミプロ作家。複数書店委託あり。棚卸しと原価管理が既に苦痛。

## 解決するペイン

1. イベント当日の頒布数を正確に記録できない(手が回らない・後でまとめて忘れる)
2. 通販が複数チャネルに散らばり、月次・年間の売上合計が分からない
3. 年末棚卸し(在庫を原価で計上)のやり方が分からない/面倒
4. 確定申告のために1年分をExcelに手入力し直す苦行

## MVPスコープ

### 入るもの

- **品目管理**: 新刊/既刊/グッズの登録(頒価、印刷部数、印刷費=原価)
- **イベント記録**: イベントごとに持込数・頒布数・売上を記録。残数は自動計算
- **当日モード**: スマホでタップ操作の頒布カウンター(即売会の売り子中に使える)
- **通販売上記録**: チャネル別(BOOTH/とら/メロン/その他)の月次売上入力
- **経費記録**: 印刷費、イベント参加費、交通費、資材費のカテゴリ別記録
- **ダッシュボード**: 品目別・イベント別・チャネル別の損益、年間サマリー
- **棚卸しレポート**: 年末在庫を原価法で自動集計
- **CSVエクスポート**: 確定申告・会計ソフト取込用

### 入らないもの(非ゴール)

- 会計ソフト機能そのもの(仕訳・申告書作成はfreee/弥生の領分。CSV連携まで)
- 各ECサイトとのAPI自動連携(v2以降。MVPは手入力+CSVインポート)
- 複数人サークルの権限管理
- ネイティブアプリ(MVPはPWA対応のWebアプリ)

## 技術構成(案)

- フロント: Web(SPA)+PWA(オフラインで当日モードが動くこと=必須要件)
- データ: まずローカルファースト(IndexedDB)+エクスポート。アカウント/同期はv2
- ホスティング: 静的ホスティング(GitHub Pages / Cloudflare Pages)
- 決済: 買い切りライセンスキー(Stripe Payment Links or BOOTH販売 — BOOTH販売は市場内流通という強みあり)

## 収益モデル

- **買い切り ¥2,980**(想定。LPで価格感応をテスト)

- 事前登録者には早期割引(¥1,980)を提示 → LP登録の動機付け
