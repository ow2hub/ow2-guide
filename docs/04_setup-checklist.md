## A. 事前登録フォームを作る(Google Forms・無料)

1. https://forms.google.com で新規フォーム作成。タイトル「シフトリズム 事前登録」
2. 質問を2つだけ作る(多いと登録率が落ちる):
   - **Q1 メールアドレス**(記述式・必須。設定→回答→「メールアドレスを収集する」でも可)
   - **Q2 勤務形態**(ラジオボタン・必須): `2交代(日勤/夜勤)` / `3交代(早番/遅番/夜勤)` / `その他・変則`
3. 「送信」→ リンクアイコン → 短縮URL(`https://forms.gle/xxxx`)をコピー
4. `lp/index.html` の `const FORM_URL = "..."` をそのURLに差し替え

## B. アクセス計測を入れる(GA4・無料)

1. https://analytics.google.com でプロパティ作成 → データストリーム(ウェブ)を追加
2. 「測定ID」`G-XXXXXXXXXX` をコピー
3. `lp/index.html` の先頭にある `<!-- ▼ GA4 ... ▼ -->` のコメントを外し(`<!--` と `-->` を削除)、
   2箇所の `G-XXXXXXXXXX` を自分の測定IDに差し替え

## D-0. 課金を暴走させない安全設計(カード登録の不安対策)

広告はサブスクではなく「掲載されたぶんだけ後払い」。停止すれば課金も止まる。
「止め忘れ」による無限課金を物理的に防ぐため、必ず以下を設定する。

1. **終了日を設定**(最重要): 各キャンペーンに開始日+**7日後の終了日**を入れる。止め忘れても自動停止。
2. **1日予算 ¥700**: 1日にこれ以上は使われない。
3. **X は総額予算 ¥5,000 を設定**: ハードキャップ。達したら停止。
4. → これで最悪放置しても上限は概ね「¥700 × 7日 ≒ ¥4,900/媒体」。

### 採用: プリペイドカード方式(A案)
Google の「前払い(手動支払い)」は日本の新規アカウントでは選択不可のため、
**プリペイドカード(Kyash)に¥10,000だけチャージして登録**する方式を採用。
残高以上は物理的に課金不可能=前払いと同じ安心。

#### Kyash 発行〜チャージ(所要10分)
1. スマホに「Kyash」アプリをインストール(iOS/Android)
2. 電話番号で登録(SMS認証)→ **Kyash Card Virtual が即発行**(番号・有効期限・CVV が表示)
3. 「チャージ」→ **¥10,000** を入金(他社クレカ/デビット・銀行口座・コンビニ・ペイジー・ATM 等)
   - ここで入れた額が上限。多く入れなければ多く使えない。チャージは手動なので勝手に増えない
4. この1枚を **Google と X の両方に登録**(同じ¥10,000が2媒体合計の上限になる)

#### 二重の安全
- カード残高¥10,000(物理キャップ)＋ D-0 のキャンペーン設定(終了日・1日¥700・X総額¥5,000)
- 実支出は7日テストでは上限まで届かないのが普通。最悪でも¥10,000で頭打ち。

#### 注意
- Kyash Card Virtual には1回/1ヶ月の利用上限あり(¥1万なら問題なし)。本人確認で上限UP。
- 広告側が少額の与信(オーソリ)をする場合あり → 残高が足りていれば通る。
- 残高不足で請求が失敗しても **広告が一時停止するだけ(過剰請求なし)**。少額の未払いが
  残ったら Kyash に追加チャージして精算すれば解消。

### テスト終了後の完全停止
- キャンペーンを「一時停止」または「削除」→ 以後の課金なし。
- 不安なら お支払い設定からカード情報を削除、アカウントも解約可能(未払い残高の精算のみ発生)。
