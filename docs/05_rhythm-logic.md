# ステップ5準備: 生活リズム提案ロジック(初稿・要オーナー添削)

これはアプリの心臓部。「シフト種別を入れたら、いつ寝て・光・食事・仮眠・カフェインを
どう提案するか」のルール表です。**根拠は下記の一般的知見に接地**していますが、
最終的な正解データは当事者(=あなた)の実感です。各行の「実感メモ」を埋める/直す形で添削してください。

> 免責: これは一般的な生活リズムの整え方であり、医療上の助言ではない(アプリにも明記)。

---

## 大原則(全パターン共通)

1. **順回し**: シフトは「早番→遅番→夜勤」の前進方向が体内時計に同調しやすい(逆回しは負担大)。
   ローテを登録すると、逆回し区間には「切替がキツい注意」を出す。
2. **光のコントロール**: 起きていたい時間は明るい光、寝たい時間の前は光を避ける
   (夜勤明けの帰宅時はサングラス/帽子、寝室は遮光)。
3. **カフェインの締切**: 就寝の6時間前以降は避ける(効果4〜6時間持続のため)。
4. **食事と仮眠は3時間あける**。就寝直前の重い食事も避ける。

## 3交代のルール表(勤務時間は例。アプリ内で編集可)

### 早番(例 6:00–14:00)
| 項目 | 提案 | 実感メモ(添削欄) |
|---|---|---|
| 就寝/起床 | 21:30就寝 / 5:00起床(約7.5h) | |
| 光 | 起床後すぐ明るい光を浴びる | |
| 食事 | 朝5:15・昼12:00・夕18:30 | |
| 仮眠 | 基本不要 | |
| カフェイン | 〜15:30まで | |

### 遅番(例 14:00–22:00)
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 就寝/起床 | 24:30就寝 / 8:00起床 | |
| 光 | 午前に光を浴びて起こす | |
| 食事 | 朝8:30・昼13:00(出勤前)・夜21:00は軽め | |
| 仮眠 | 眠ければ13:00頃に20分 | |
| カフェイン | 〜18:00まで(帰宅後の入眠を守る) | |

### 夜勤(例 22:00–翌6:00)
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 出勤前仮眠 | **14:00–16:00に90分**(起床から約8h後が目安) | |
| 光 | 勤務中は明るく保つ / 帰宅時は光を避ける | |
| 食事 | 出勤前に主食 / 深夜は軽食 / 明けの朝は軽め | |
| 夜勤中仮眠 | 眠気ピークの**2:00–4:00に20分以内** | |
| カフェイン | 夜勤前半までに。**明け方(帰宅3〜4h前)以降は摂らない** | |

### 夜勤明け(帰宅後)
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 昼の睡眠 | **2時間程度で切り上げる**(深く入りすぎない) | |
| 起床後 | カーテンを開けて光を浴び、普段通りに過ごす | |
| 夜 | **早めに就寝して体内時計をリセット**(翌日休/早番へ接続) | |
| 注意 | 帰宅→そのまま夕方まで爆睡は夜眠れなくなる悪循環 | |

### 休
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 方針 | 前日が夜勤明けなら「リセット済みの起床時刻」を維持。寝だめしすぎない | |

## ★ オーナー実シフト版(2交代・昼勤/夜勤・遅番なし・1回10.5〜11h)

オーナーの実勤務(2026-07 聞き取り)。この4種を最優先で作り込む。長時間シフトのため、
「勤務外の睡眠をどこに固めるか」が肝。※提案の分岐は「次の勤務が何か」で変わる(下部・切替参照)。

### 昼勤・普通(8:30–19:00)
| 項目 | 提案 | 実感メモ(添削欄) |
|---|---|---|
| 就寝/起床 | 23:30就寝 / 6:45起床(約7.25h) | |
| 光 | 起床後すぐカーテンを開ける / 通勤で自然光 | |
| 食事 | 朝7:00・昼(休憩)12:30・夕は帰宅後19:45を軽め | |
| 仮眠 | 帰宅後の仮眠はNG(夜眠れなくなる)。眠ければ昼休憩に10〜15分 | |
| カフェイン | 昼休憩(〜13:00)まで。遅くとも15:00 | |

### 昼勤・早出(8:00–18:30)
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 就寝/起床 | 23:00就寝 / 6:15起床(普通昼勤より30分前倒し) | |
| その他 | 光・食事・カフェインも30分前倒しで同じ考え方 | |

### 夜勤・普通(22:00–翌8:30)
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 出勤前の主睡眠 | **昼〜夕に固める: 14:00–18:00(約4h)**。長時間夜勤に備え、しっかり寝る | |
| 光 | 勤務中は明るく保つ / 帰宅時(8:30)はサングラス・帽子で光を避ける | |
| 食事 | 出勤前18:30に主食 / 深夜1:00〜2:00に軽食 / 明けの朝は軽め | |
| 夜勤中仮眠 | 眠気ピークの**2:00–4:00に20〜30分** | |
| カフェイン | 前半(22:00〜1:00)に。**明け方4:00以降は摂らない**(帰宅後の睡眠を守る) | |

### 夜勤・早出(21:00–翌8:00)
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 出勤前の主睡眠 | 13:00–17:00(約4h)。普通夜勤より1時間前倒し | |
| カフェイン締切 | 明け方3:00以降は摂らない | |
| その他 | 光・食事は普通夜勤と同じ考え方で1時間前倒し | |

### 夜勤明け(帰宅 8:00〜8:30)※次の勤務で分岐
| 次が… | 提案 | 実感メモ |
|---|---|---|
| また夜勤 | 帰宅後 9:30〜14:00頃に**しっかり寝て夜勤リズムを維持** | |
| 休 or 昼勤 | 昼の睡眠は**2〜3時間で切り上げ** → 夜に早め就寝で**リセット** | |
| 共通 | 帰宅時は光カット。寝室は遮光。就寝直前のスマホ・重い食事を避ける | |

### 昼勤↔夜勤の切替日
| 項目 | 提案 | 実感メモ |
|---|---|---|
| 方針 | ブロックの切替は1〜2日かけて就寝時刻を段階移動(いきなり真逆にしない) | |
