# 第2回の名寄せ表(canonical.json)について

179表現 → **124種類**(59件を統合)。

## 統合の方針

**同じ行動を別の言い方で書いているものだけ**をまとめた。
近いけれど別の行動は、あえて分けている。

まとめた例:

- 「タイムログを記録する」「時間を記録する」「時間を見える化する」
  「時間の使い方を把握する」→ **時間の使い方を記録する**
- 「仕事を委任する」「人に仕事を任せる」「仕事を抱え込まない」→ **仕事を人に任せる**
- 「デジタルから離れる」「テクノロジーから離れる」→ **デジタルデトックスを習慣化する**

分けたままにした例:

| 分けたもの | 理由 |
|---|---|
| 人生の優先順位を明確にする / 優先順位をつける | 前者は価値観、後者はタスク処理 |
| スマホ通知をオフにする / 就寝前にスマホを手放す / デジタルデトックス | 前2つは具体的な別々の操作 |
| 睡眠時間を確保する / 睡眠効果を活用する | 確保することと、活用することは別 |
| 最初の10分を検証する / 定期的に振り返る | 前者は特定の時間帯に限定された話 |
| 家事の時間を減らす / 時短家電を活用する | 後者は手段のひとつ |
| 休息を予定に入れる / 休みを全力で楽しむ | 確保と使い方は別 |

**ここを緩くすると「共通点が多い」という結論を作れてしまう。**
迷ったものは統合しない側に倒した。
