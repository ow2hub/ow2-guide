# 復旧用ファイル

`responses/` に保存されるはずだった抽出結果が空だったため、チャット上に残っていた
run1 の返答をここに保存してある。あわせて、その内容をもとに作った名寄せ表も置く。

使い方:

```bash
cp recovered/batch1_run1.txt responses/
cp recovered/canonical.json .
python3 aggregate.py
```

canonical.json の内訳(グループ分けの根拠):

| まとめた名前 | 元の表現 |
|---|---|
| 時間の使い方を見直す | 時間の使い方を見直す / 限られた時間を活かす / 効率的に時間を使う / 日常の無駄を削る / 短い時間を活用する / 時間を資産として扱う |
| やることを減らす | 仕事を減らす / タスクを手放す / やらないことを決める / 余白をつくる |
| 意識的に休む | 休息を戦略として取る / 怠けと考えずに休む / 仕事以外の時間を確保する / 休む時間を大切にする |
| 意志力に頼らない | やる気に頼らず動く / 疲れに左右されず動く / 意思の力に頼らず動く / 無理なく続ける |
| 自分に合うやり方を選ぶ | 身近なものでタスクを始める / 自分に合う方法を試す |
| タスクを見える化する | タスクシュートを始める / 予定とタスクを整理する / ウィークリーページを使う / 1週間単位で管理する |
| まとまった時間を確保する | 勉強時間を確保する / 副業・勉強に時間を使う |
| すぐ着手する | 仕事にすぐ取り掛かる / 判断を素早くする |
| 時間を区切って使う | 朝の10分を整える / 1日を7ブロックに分ける |

以下は統合していない(別物として残した):
AIに仕事を任せる / スマホから時間を取り戻す / 仕事前の準備を見直す /
優先順位をつける / 完璧主義をやめる
