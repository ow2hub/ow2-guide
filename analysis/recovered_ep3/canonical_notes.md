# 第3回の名寄せ表について

124表現 → **80種類**(52件を統合)。

第2回(179→124 / 59件統合)と**同じ基準**で作っている。統合率は第2回33%・第3回35%で、
基準を緩めたり厳しくしたりはしていない。ここが揃っていないと、
「時間術より読書術のほうが共通点が多い」という比較そのものが成立しない。

## 方針

**同じ行動を別の言い方で書いているものだけ**をまとめる。迷ったらまとめない。

まとめた例:

- 「速読の技法を使う」「超速読する」「フロー・リーディングを実践する」→ **速読する**
- 「知識と知識をつなげる」「他人の知識を自分につなげる」「つながりを意識して読む」
  「経験と知識を結びつける」→ **知識をつなげて読む**
- 「本との対話を続ける」「本にツッコミを入れる」「著者と議論する」→ **本と対話しながら読む**

## 分けたままにしたもの

| 分けたもの | 理由 |
|---|---|
| 速読する / **速読より熟読する** | 逆の主張。まとめたら意味が消える |
| 速読する / 本を2割だけ読む / 読むべき箇所を見極める | 「速く読む」と「一部だけ読む」は別の行動 |
| 読んだ内容を記憶に残す / **忘れることを前提に読む** | 前提が正反対 |
| 読んだ内容を人に話す / SNSやブログで発信する | 相手が目の前にいるかどうかで行動が変わる |
| 読書を習慣化する / 月20冊の読書習慣をつくる | 後者は具体的な目標値を伴う別の主張 |
| 本を再読する ← 1冊を5回読む | ※ここは統合した(同じ行動の強度違いと判断) |
| 読書感想文を書く / 読んだ本のポップを書く | 書く対象も長さも違う |
| 本と対話しながら読む / 著者の問題点を見つける | 後者は分析読書の一手順 |
| 複数の本を関連づけて読む / 1テーマ5冊読む | 後者は冊数を指定した別の主張 |

**ここを緩くすると「共通点が多い」という結論を作れてしまう。**
第2回と同じく、迷ったものは統合しない側に倒した。
